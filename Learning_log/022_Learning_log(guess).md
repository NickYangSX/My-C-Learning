## 1 游戏基础：
游戏基础：
#include <stdio.h>
#include<stdlib.h>
#include<time.h>
int main(){
srand(time(0));
int a=rand();
printf("%d\n",a);
 return 0;
}
其中：srand全名Set Random Seed，也就是在电脑里随机抽取一个"种（数子表）"
time(0):获取时间截（1970.1.1到现在这一秒），保证数字相对随机。
srand(time(0)):就是在声明时间截里面截取一个种子。要求必须放在main函数最开头的位置，而且绝对不能放循环体里面，电脑会炸。
rand():从srand里面给的种子里按照某种算法算出下一个数是什么。（抽一个数）
}
## 2优化迭代
我们只需要利用除号余数%进行控制数字的区间
将变量a%100，可以限制输出数目在0到99之间
为什么？余数相当于任意一个数的个，十位，无论原数字是多少，只要取余数，就可以显示个位,十位，并且限制在100以内（特殊：100%100=0，偶数个0的数字结果为0）
重要规律：1.限制范围：任何数除以N，余数一定在0到N-1之间。
2.边界偏移，只需要把整个算式+ -N即可
万能公式：rand() % N + 1 （N代表你要的区间大小）
例如：rand() % 100 + 1 （限制在 1 到 100 之间，包含 1 和 100）
## 3结合要点与循环，编写游戏
do_while作用：do保证在循环开始前给予玩家猜测机会，否则直接进入循环不合理
猜数字就是猜错的循环里逐渐走向猜对输出的过程，所以，我们需要保证猜数字的循环条件是玩家猜错，也就是a!=number,而玩家猜对了，不符合循环条件，游戏才得以结束并且输出内容
## 4关于VS平台的一些格式调整
在VS里面，scanf只能写成scanf_s，否则报错，而且黑格子界面可能会在猜对的一瞬间一闪而过
解决方法：1.#define _CRT_SECURE_NO_WARNINGS加在最最最前面，前于#include <stdio.h>，这是在告诉VS：不要在意这种形式细节
2.在 return 0; 前面加一句 system("pause");，它会提示“请按任意键继续...”，把窗口卡住。（当然集成的VS就不会这么干了）
更优雅的架构师做法是：别按 F5，直接按 Ctrl + F5 启动但不调试，VS 会自动帮你暂停。
