# 二维数组定义
defination：如果把一维数组作为元素，形成一个新的数组，就称新数组为二维数组，也就是一维数组变成了行，列是二维数组的核心
# 格式
type arr[][]
如 int a[1][2]
double b[2][3]
其中，第一个[]表示行，[]表示每行有多少个元素，也就是列
# 初始化
不完全初始化：只初始化一部分，剩余用0补齐
int a[3][5]={1,2,3}
`attention:c里第一行是0，第一列也是0，所以要第一行第一列的数应该是a[0][0]`
注意，第一行的第一个数子是1，第一行是1，2，3，0,0
第二行被0补了，是0，0，0，0，0
int b[3][5]={1,2,3,4,5,6}
在一维数组里，数字超了就报错，本质是因为没格子放了。但是在二维，格子是不止一行的，多余的就会放在第二行
也就是说，第一行1，2，3，4，5
第二行6，0，0，0，0
完全初始化：把里面所有格子手动填满
int a[2][3]={1,2,3,2,3,4}
第一行:1,2,3
第二行:2,3,4
数字按行初始化：在大括号里面再加上一个大括号即可
int a[3][5]={{1,2},{2,3},{3,4}}
结果第一行1，2，0，0，0
第二行2，3，0，0，0
第三行3，4，0，0，0
不可以省略列：二维数组就是因为多行才成立，如果列被省略就会导致直接变成一维数组,哪怕就像上面按行分布大括号里大括号也不行
int a[][4]={1,2,3,4}其他0补全
地址得这么算：a[i][j] = 开头 + i*列数 + j。这个"列数"必须写死在类型里（[5] 那个位置），编译器才能算
