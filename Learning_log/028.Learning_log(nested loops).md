# 嵌套循环的使用思路
1.外层跑一轮，内层跑一圈
外层每执行一次循环体，内层循环都要完整地从初始值跑到条件为假；内层跑完后，外层才进入下一轮
2.确定外层内层，以及大对象和小对象
写代码前，问自己：
对每个 ___，我要做 ___。
第一个就是大对象，第二个就是小对象。大对象是你外层循环每轮要处理的那个“独立单元”，它可能是最终结果，也可能是被筛选的候选；小对象是“处理当前大对象时，内部要遍历/检查的那一串东西”；
判断方式
变化慢的是外层大对象
翻书法——页大行小:我最终是在一页一页地处理，还是一行一行地处理？
检查：如果只写一层循环，能不能表达我的意思？
3。定计数（尤其是遇到那种前50个，前n个的）
计数器保证算到什么时候是个头，这种一般就是while了，因为不知道循环次数
计数器跟结果走，不跟过程走；写在外层，不写内层
4.定前进——外层对象无条件往后走
也就是最后的x++,防止死循环
类似：
int x = 起始值;          // 角色1：外层变量，管“查谁”
int cnt = 0;             // 角色3：计数器，管“停不停”

while (cnt < N) {        // 第1步：外层框架，由计数器控制
    int ok = 1;          // 先假设合格

    for (i = ...; i < x; i++) {   // 第2步：内层检查，边界可依赖 x，for (内层变量 = 内层起点; 内层条件; 内层变量更新) {
        if (不合格) {
            ok = 0;
            break;       // 铁律4：只跳内层
        }
    }

    if (ok) {            // 第3步：内层结束，外层决定
        输出/保存 x;
        cnt++;           // 铁律5：成功才加，写外层
    }

    x++;                 // 第4步：外层无条件前进
}
