## 数组
数组(array)：`相同类型`组成的`有序`集合,并且以`连续`的方式存储，相当于元素集合<br>
推导:数组里面`至少有1个元素`，元素数量不能为0<br>
一维数组：<br>
创建形式:type arr_name[常量值，也就是数字]<br>
type指的是数据里面存放数据元素的类型，是`数组的类型`，可以是int float char 也可以是自定义的类型<br>
arr(array缩写)_name(数组的名字)<br>
[]里面的常量值是指数据的数量，也就是数组的大小<br>
例子:int math[20]<br>
# 数组初始化
只需要把初始化的值用大括号括起来，其他和变量初始化的差异不大<br>
例子: int math[10]={1,2,3,4,5,6,7,8}<br>
1.注意，我`初始化的数量和常量值不一致，且小于`这个时候计算机会在后面自动补数个0，直到数量和常量值一致<br>
结果:{1,2,3,4,5,6,7,8,0,0}<br>
`大于`呢？<br>
系统报错<br>
那`没有常量，但是有初始化呢`<br>
常量值会根据初始化的数量值进行自动补全<br>
int math[]={1,2,3,4,5,6,7,8}//编译器补全数组长度自动为8<br>
int math[10]={1,2,3,4,5,6,7,8}//10个<br>
# 数组类型
int 是声明变量种类<br>
int[常量值]是声明数组种类，(arr是名字)<br>
int math 变量<br>
int[10] char[10] 数组 注意：个数也会决定类型<br>
int[10] int[5]不一样<br>
2.注意：浮点数有可能在内存里面没办法精确保存，导致数组显示的值会有偏差<br>
