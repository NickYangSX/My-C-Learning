## 数组
数组(array)：`相同类型`组成的`有序`集合,并且以`连续`的方式存储，相当于元素集合
推导:数组里面`至少有1个元素`，元素数量不能为0
一维数组：
创建形式:type arr_name[常量值，也就是数字]
type指的是数据里面存放数据元素的类型，是`数组的类型`，可以是int float char 也可以是自定义的类型
arr(array缩写)_name(数组的名字)
[]里面的常量值是指数据的数量，也就是数组的大小
例子:int math[20]
# 数组初始化
只需要把初始化的值用大括号括起来，其他和变量初始化的差异不大
例子: int math[10]={1,2,3,4,5,6,7,8}
1.注意，我`初始化的数量和常量值不一致，且小于`这个时候计算机会在后面自动补数个0，直到数量和常量值一致
结果:{1,2,3,4,5,6,7,8,0,0}
`大于`呢？
系统报错
那`没有常量，但是有初始化呢`
常量值会根据初始化的数量值进行自动补全
int math[]={1,2,3,4,5,6,7,8}//编译器补全数组长度自动为8
int math[10]={1,2,3,4,5,6,7,8}//10个

int[常量值]是声明数组种类，(arr是名字)
int math 变量
int[10] char[10] 数组 注意：个数也会决定类型
int[10] int[5]不一样
