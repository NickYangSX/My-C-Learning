#2 递增递减运算符++ --是单目运算符，只能一个算子。但是有个特殊要求：后面要跟变量而不是具体数值。++：变量+1 --反之
count++就是count+=1就是count=count+1
++--可放变量前面和后面，前面叫前缀形式，后面反之
a++是a加1以前的值。++a是以后的。
注意，一旦出现++a,a++，那么计算机就会根据这俩公式算，源代码里面分别出现了，计算机根据他们的位置和时间进行计算，这就是为什么两个total名称一样位置不同结果就不同
源代码里面，运算式子是total++,++total,在算的时候是一个逻辑。所以第一个printf里面输出为2，而表达式里面++total就是被加之前的状态，所以第二个
printf里面total++为2，第三个就是4
例子：int a=1;
int b=a++//先赋值再加，意思是b是a被+1前的状态，所以b=1，但是a++已经存在代表他一定要被+1，所以a=2

 int a=1
 int b=++a//先加再赋值，意思是b是a被+1后的状态，所以b是2.但是++a算式存在，所以a最后也是2
