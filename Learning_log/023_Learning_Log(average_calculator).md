## 1思路
计算平均数，就需要综合sum，个数count，以及组成sum的数字number，计算sum很简单但是计算count就需要while循环。
我们也需要一个跳出与下一步的指令，因为scanf是没输入数字限制的，正常回车无法成为下一步指令，我们需要在不额外添加什么的情况下进行下一步，while条件可以成为下一步的指标。
## 2关于背后逻辑以及误区
scanf的指令是我要读数，但是没有上限，因为没规定回车是下一步（之前的代码也没规定，是到数字上限自动进入下一步的）那么就导致它一直在读数但是就是不下一步，形成一个死循环
但是反应过来翁恺在while里面加了俩scanf，第一个scanf保证输入东西但是不在循环体里，第二个 scanf 去等待你的第二个输入，也就是折回到第一个scanf。                    （相当于你每个输入的数字无论先后在输入的那一刻先在while外然后瞬间输入到循环体里，这个代码并没有写任何下一步执行动作控制代码，你第一个输入的数字，输入的那一刻，已经在循环体里，如果你直接输入-1，下一秒直接报错）
当你输入完第二个数字，它便带着这个新值然后回去和while条件判断，然后直接在后台算好答案存在内存里但是不显示（因为还没执行printf），直到你输入-1打破循环才显示。一旦是-1那么第二个输入界面就会关闭，也就是不在让东西进去while里面，也就促成了下一步的作用，把-1之前所有数字开始运算-1就是个门
在do-while里面，scanf是直接在循环体里面，这个时候只是省了一个把输入的数字带入循环体的步骤，但是判断是一样的。也就是输入的时候就已经是在循环体里面了。
## 3例子如下
scanf("%d", &number);  // 【第1步】程序在这里停下，接住了你的 5。此时 number = 5。
while ( number != -1 ) { // 【第2步】判断：5 != -1，成立！进入循环。
    sum += number;       // 【第3步】计算：sum = 0 + 5 = 5。
    count ++;            // 【第4步】计数：count 变成 1。
    scanf("%d", &number); // 【第5步】（高能预警！）程序走到这里，再次停下了，回到步骤一等着你的下一个数字。
}
