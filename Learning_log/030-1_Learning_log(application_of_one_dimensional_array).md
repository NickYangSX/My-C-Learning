# 数组的下标
下表就是每个元素的编号，下标从0开始，第一个元素下标0，最后一个是n-1。比如
int math[10]={1,2,3,4,5,6,7,8}，里面1对0，8对7
[]是下标引用符，用来查下标对应的值
pritnf("%d",math[6]) 找到元素7
我们也可以用下标引用操作符修改编号对应的元素，如
math[6]=70,那么后续编号6对应的就是70
