源代码
int n;
scanf("%d",&n);
int fac=1,i=1;
while(i<=n){
fac*=i;
i++;}
这是阶乘：n！
for专门解决阶乘
for(初始化条件;范围条件;计算条件，循环内容完毕后轮到这里的计算条件）{ //这些条件是在循环开始前就判定的，和while一样，条件但凡不成立，不会循环，所以for不是do_while
符合赋值运算式；
}
原文while可替换
int n;
scanf("%d",&n);
int fac=1,i=1;//此处int i=1可以并入for条件里
for(i=1;i<=n;i++){ //i<=n是复制死循环，而（int i=1）是C99才能这么写；i如果是i--,那么循环会变成负数，也就是反向循环
fac*=i; 
}
求和初始化应该是0，阶乘则1
C99可以像上面这么写，但是此外的需要加-std
反向循环：
for(i=m;i>1;i--){
fac*=i
}//这个循环会反向循环
也可以
int n=m;
for(m=m;m>1;i--){ //一定注意要用其他变量表示这个变量，否则导致printf出错,m=m甚至可以空着不写，但是；不能漏
fac*=i
}
printf("%d",n);//如果此处是m，假设一开始是输入5，结果应该是5！=120，但是由于m在循环体里面参加变动，最终显示1!=120
