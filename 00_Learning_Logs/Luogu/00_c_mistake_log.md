## 3 向上取整公式（a+b-1)/b
多用于算时间差的时候遇到浮点数导致结果向下取整
a/b=c.....d
向下取整，结果为c，错误。则需要c+1.
向上取整公式如此
推导：判定条件：1.d=0,不进位
               2.d>0，进位（全程需要，思路核心）
a/b=c...d 即a=bc+d
同除b a/b=c+d/b
d/b这个是剩下部分占一个b的比例，对于余数d也就是0<=d<b，d/b大于等于0小于1
因为程序里除法是向下取整，所以直接算a/b只能得到c，无法区分“d=0”和“d>0”。
为了用向下取整实现向上取整，我们希望在分子a上加一个待定的量x使得
(d+x)/b=0或>0，分别让这个式子向下取整为0或1
讨论1.递进值 这个递进值=0时 d/b+x/b=0,x/b=0,但是由于小数取整是0，所以x应该是一个取值区间
0<=x<b（只要不让小数等于1）
 该值>0,（d+x）/b>0,这个进位值进一位应该为1保证判定条件2的情况。
(d+x)是否应该有1个b一样大小，并且只进一位数？
推出 b<=(d+x)<2b 
此时来研究d，因为这个变量目前没任何信息
讨论2.余数d 条件1 d=0不进，(别忘记d是余数)，x/b=0
x/b为小数(也就是整数部分为0)，也就是0<=x/b<1，不进的
x/b<1 已知b/b=1,那么x<b
 条件2 d>0,进位，(d+x)/b>0,
 2>(d+x)/b>=1,(d+x)>=b x>=b-d,d可以是任何大于0小于b
 的正整数。如若d=1，那么x>=b-1,(d上升，x下降，x取值范围扩大)
 进位，也就是说起码d+x要大于等于b，我们需要找一个值，使得d+x刚刚凑合的到b的值
条件1 x<b 条件2 x>=b-1 结合b-1<=x<b 取整只能x=b-1
带回原来式子
(a+x)/b=(a+b-1)/b=/b
# 向下取整
次数=(终值-初值)/步长（+1）
终值-初值）/步长：在这段距离里可以走几步
+1：起点也要算进去的情况（初值本身也会被算一次）
什么时候不加一：1.开区间，如for循环条件里的<或>
 2.算距离时不加1
## 4关于ceil()函数
这个就是向上（大）取整函数，完全可以替代向上取整公式
使用方法：
1.引入数学#include<math.h>
2.格式double result = ceil(x)
x可以是整型或者浮点型，但是返回值必须是double型(如果需要其他类型见下方强制变量类型转化）
例子：
    printf("%f\n", ceil(2.1));    // 3.000000
    printf("%f\n", ceil(-2.9));    // -2.000000，-2大于-3
    printf("%f\n", ceil(2.0));    // 2.000000
    printf("%f\n", ceil(0.1));    // 1.000000
    与之相反的是floor
(int) 是“向零取整”：正数时等同 floor，负数时等同 ceil。
ceil 和 floor 永远方向相反（除非本来就是整数）。
三者只有在“一个正小数、一个负小数”对比时才会呈现出三种不同结果。
## 5关于强制变量类型转化

注意：同一变量不可重复定义（比如 float a=。。。；int a=（int）（a）是错误的，可以改int a1=(int)(a)
格式 (目标类型)(表达式)

int b = (int)a;    // b = 3
printf("%f",a)//依旧输出a=3.700000

## 6卫语句
卫语句就是：把排除错误情况、边界情况的 if 写在最前面，写完立刻 return 或者 continue，这样剩下的代码就全是最核心的正常逻辑了
for (int i = 0; i < n; i++) {
    if (arr[i] == target) {
        printf("找到了！");
        break; // 也是一种卫语句：找到了就立刻收工，别浪费时间继续找
    }
}
对比：嵌套（未使用卫语句）
for (int i = 0; i < n; i++) {
    if (score[i] >= 60) {  // 只有及格的才处理
        sum += score[i];
    }
}
使用卫
for (int i = 0; i < n; i++) {
    if (score[i] < 60) {
        continue; // 不及格的直接滚蛋，别碍事
    }
    // 这里只剩及格的分数了，专心算总分
    sum += score[i];
}

## 7辗转相除法(Euclidean algorithm)
多用于求最大公约数
方法:两数相除取余，然后除数除以余数，一直到余数为0
a%b=c;
b%c=d,且d=0
c为最大公约数
example
#include <stdio.h>
int main() {
    int a, b;
    scanf("%d %d", &a, &b);
    // 只要余数不为 0，就一直“辗转”下去
    while (b != 0) {
        int temp = a % b; // 算出余数
        a = b;            // 把原来的除数变成新的被除数
        b = temp;         // 把余数变成新的除数
    }
    // 循环结束后，b 变成了 0，此时 a 就是最大公约数
    printf("最大公约数是: %d\n", a);
    return 0;
}
