## 题目
一头大象要喝 20 升水才解渴。
现在只有一个圆桶，告诉你桶的高 h 和底面半径 r（单位都是厘米）。pi取3.14
问：大象至少要喝几桶，才能喝够 20 升？
## 解决思路
算出每桶体积，然后20L除桶数
## 方法
变量有小数，方法分为两个，一个是float double，一个是整数相除，但是都要向上取整
# 1 小数法
我们需要变量转换，也就是需要intb=(int)(a) ；而a是double这种小数型
明确变量h,r,n,V;
n=20*1000/V;由于V是浮点数，而我们需要n为整数型，就会用到变量强制转换。
但是我们需要向上取整，就会引申出：1.math.h用ceil()函数2.if手动判断
源代码1.
#include<stdio.h>
#include<math.h>
int main(void){
int h,r;
scanf("%d %d",&h,&r);
double V;
V=3.14*h*r*r;
int n=(int)ceil(20*1000/V);
printf("%d",n);
return 0;
}
源代码2.
#include<stdio.h>
int main(void){
int h,r;
scanf("%d %d",&h,&r);
double V;
V=3.14*h*r*r;
int n=(int)(20*1000/V);
if(n*V<20000)
n++;
printf("%d",n);
return 0;
}
# 整数+向上取整公式法
#include<stdio.h>
int main(void){
int h,r,n=0;//记得初始化未读取的变量，虽然这题不需要因为后面计算全是已确定数值，但是对于有n++这种自变量和有未确认计算式的变量需要初始化
scanf("%d %d",&h,&r);
int V;
V=314*h*r*r;//小数化整
n=(2000000+V-1)/V;
printf("%d",n);
return 0;
}
