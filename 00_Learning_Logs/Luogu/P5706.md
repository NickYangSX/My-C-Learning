每人与每杯（P5706 原题变体）
题目：t 毫升饮料分给 n 人，每人 2 杯。输出每人多少毫升（保留 3 位小数）和总杯数。
## code:
#include <stdio.h>

int main()
{
    double t, m;
    int n, cup;
    scanf("%lf %d", &t, &n);
    m = t / n;
    cup = 2 * n;
    printf("%.3f\n%d\n", m, cup);
    return 0;
}
## mistakes：
1. scanf 里 %lf 画蛇添足加了精度 → 写成 %.1lf
2. printf 里 \n 后面多了一个空格 → 第二行开头多了个空格字符，如下：
0.500
 1
## solution：
scanf 的格式串是输入匹配规则，它只认"读什么类型"，不认"保留几位小数"
在printf转行的时候，\n后面紧跟第二个输出值就好，不要空格，除非题目需要
