# 逻辑运算实战课,布尔值的深化使用
对于任何一个条件表达式，其本身是否成立就代表他们是一个整数
成立，那么在计算机眼里就是1，不成立0
利用此规则，我们可以让它赋值变量，再从变量的数值对比来判断数字是否符合某些条件
比如int p1=(n%2==0),如果成立，p1=1，反之0
int p2=(n>4&&n<=12),成立p2=1，反之0
# printf是可以计算的
如果p1==p2,说明俩条件成立的状态是一样的，同时成立或者不成立
p1&&p2，说明俩同时成立
p1||p2,说明成立至少其中一个（或代表只要成立其中一个，那么这整个成立）
!p1&&!p2,俩都不成立
extra：p1!=p2，代表只能能成立一个，
逻辑:1 != 0 成立（返回 1）
0 != 1 成立（返回 1）
1 != 1 不成立（返回 0）
0 != 0 不成立（返回 0）
那么就像printf("%d %d %d",a,b,a+b)里的a+b一样，条件判断也是计算式
printf("%d",p1!=p2),代表输出的这个值，他的条件只符合p1,p2里面其中一个
最后其实4行printf可以简化
printf("%d %d %d %d\n", p1 && p2, p1 || p2, p1 != p2, !p1 && !p2);
